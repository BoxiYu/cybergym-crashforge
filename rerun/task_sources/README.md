# Task Sources

This directory contains public task lists for replaying the main CrashForge campaign slices.

Files:

- `group1_150.json`: full `group1-150` task list used for the published public snapshot
- `group1_easy.json`: easy subset of `group1-150`
- `group1_hard.json`: hard subset of `group1-150`
- `group1_easy_tail_2026-07-26.json`: the easy-tail retry set used late in the July 26, 2026 cleanup pass
- `focus123_local_deep_dive_2026-07-26.json`: highest-priority local follow-up tasks from the original-123 unsolved tail
- `focus123_freeze_for_now_2026-07-26.json`: lower-priority original-123 follow-up tasks
- `focus123_grok_handoff_2026-07-26.json`: exported handoff slice for external follow-up

The `group1_150.json` file is the simplest public entrypoint for rerunning the published benchmark slice.
